SpotWarp v3.4.3 Standalone C-Binary (Windows x64)
================================================================================

SpotWarp is an automated daemon that protects your cloud GPU training runs
from spot instance evictions with continuous background workspace backups
and automatic failover to a replacement GPU on Vast.ai and RunPod.

--------------------------------------------------------------------------------
QUICK START:
--------------------------------------------------------------------------------
1. Extract this ZIP archive to a folder of your choice (e.g. C:\SpotWarp).
2. Open PowerShell or Command Prompt in that folder.
3. Run the interactive setup wizard to enter your SpotWarp license key:
     .\spotwarp.exe init

4. Start GPU protection in background:
     .\spotwarp.exe start -d
