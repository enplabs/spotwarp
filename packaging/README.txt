SpotWarp v3.5.2 Standalone C-Binary for SaladCloud (Windows x64)
================================================================================

SpotWarp is a lightweight local daemon that protects your SaladCloud GPU
training containers with continuous background /workspace backups and
automatic Same-Cloud (Salad -> Salad) checkpoint recovery upon node preemption.

--------------------------------------------------------------------------------
QUICK START:
--------------------------------------------------------------------------------
1. Extract this ZIP archive to a folder of your choice (e.g. C:\SpotWarp).
2. Open PowerShell or Command Prompt in that folder.
3. Run the interactive setup wizard to configure your SaladCloud API key & Org:
     .\spotwarp.exe init

4. Start SaladCloud protection in the background:
     .\spotwarp.exe start -d
