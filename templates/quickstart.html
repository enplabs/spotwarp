Setup Guide

Get SpotWarp running in 1 minute

Three simple steps. Your credentials stay 100% local — zero cloud key uploads.

1

Install SpotWarp

on your local machine / server

Works on Linux, macOS, and Windows. No root or sudo required.

terminal (any OS)
pip install --upgrade spotwarp
2

Run One-Time Quick Setup

100% local config

Interactive wizard saves your keys locally to ~/.spotwarp/config.json so you never need to export environment variables again.

terminal (any OS)
spotwarp init
Enter your SpotWarp License Key (or start with trial key) and Vast.ai API Key. RunPod key is optional for cross-cloud fallback.
3

Start the Guard

instant protection

Run in the foreground or detach as a 24/7 background daemon with -d.

Option A: Foreground Live Console
spotwarp start
Option B: 24/7 Background Daemon
spotwarp start -d
💡 Training Auto-Resume: To automatically resume training on replacement GPUs, add:
spotwarp start --resume-cmd "python train.py --resume"
4

Daemon Management & Status

cli commands
Check Status
spotwarp status
Stop Daemon
spotwarp stop
